## Architecture Principles

```text
01. Keep the architecture understandable.
02. Optimize after measuring.
03. Treat the database as part of the architecture.
04. Cache intentionally, not automatically.
05. Design APIs around clear contracts.
06. Automate repetitive operational work.
07. Build observability into production systems.
08. Security is part of engineering, not an afterthought.
```
